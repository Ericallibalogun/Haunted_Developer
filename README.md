# 🎃 Haunted Developer

**Kiroween Hackathon Project - Milestone 1: Skeleton Crew Foundation**

A spooky collection of modular skeleton templates for developers who dare to code in the dark.

## 👻 What's Inside

### Ghost Chat App
An AI-driven haunted chatbot interface that brings supernatural conversations to life. Perfect for building eerie interactive experiences with AI.

### Zombie Game Engine
A mini haunted 2D game engine for developers. Create spine-chilling browser-based games with this lightweight, modular engine.

## 🦴 Getting Started

Each template is self-contained in its own directory:
- `ghost-chat/` - Haunted chatbot interface
- `zombie-engine/` - 2D game engine foundation

Explore each directory for specific setup instructions.
